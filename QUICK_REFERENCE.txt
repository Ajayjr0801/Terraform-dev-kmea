⚠️ IMPORTANT NOTES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. RDS Password
   • Auto-generated by AWS Secrets Manager
   • NOT stored in tfvars (security best practice)
   • Retrieve: terraform output rds_secret_arn

2. EKS API Access
   • Private endpoint only
   • Access from jumphost or within VPC only
   • Command: aws eks update-kubeconfig (from jumphost)

3. S3 Buckets
   • All private, no public access allowed
   • Only accessible via CloudFront CDNs
   • 404/403 errors redirect to /index.html (SPA routing)

4. API Gateway
   • NOT managed by Terraform
   • Create manually in AWS Console
   • Connect to internal ALB via VPC Link

5. Jumphost SSH
   • Currently DISABLED (empty CIDR list)
   • SSM Session Manager is always available
   • To enable SSH:
     - Add your IP: jumphost_allowed_ssh_cidrs = ["X.X.X.X/32"]
     - Create EC2 key pair in ap-south-1
     - Set: jumphost_key_name = "your-key"
     - Re-apply: terraform apply -var-file=terraform.tfvars

Bootstrap bucket exists:
  aws s3 rm s3://kmea-dev-tfstate-ap-south-1 --recursive

Terraform init fails:
  rm -rf .terraform
  terraform init

EKS not accessible:
  • Check jumphost is running
  • Verify security group 443 rule exists
  • Confirm within VPC access only

RDS connection fails:
  • Verify RDS in private subnet ✓
  • Check RDS security group rules
  • Wait 5-10 min for DNS propagation
